Orion — one screen, two surfaces

Fig. 3 · Lifters · Sep 2024 → now

A multi-brand, regulated sports betting and casino platform. I work on the front end, in React 17 and TypeScript, and on the back end, in Java and Spring.

What I built

  • Desktop Profile and Wallet: Pix deposits with QR code, and withdrawals. The deposit and withdrawal modals became the desktop modal standard; on mobile they become a bottom sheet.
  • VIP Club, with gamification tiers served by a single cached hook, and the new mobile Home.
  • Java and Spring back-end work on the features I ship, and pull request reviews for the team.

Decisions

  • Reuse without forking. Each mobile screen becomes a sheet 31 inside the desktop shell 33, mounted by the section registry 34 through an additive prop 35 and scoped CSS. Nothing from desktop leaks into the mobile drawer 32.
  • Extract, don't copy. The bonus hub logic moved out of the mobile component into a module shared by both surfaces.
  • Measured fidelity. Computed styles compared against the Figma tokens, not eyeballed.

Materials React 17 · TypeScript · Redux Toolkit · SCSS · Java 21 · Spring Boot · PostgreSQL · Redis · RabbitMQ

Smartico Pages — JavaScript where scripts are not allowed

Fig. 4 · Lifters · 2026

Gamification pages (store, missions, tournaments and mini-games) for two brands on a Sportingtech platform, using the Smartico SDK. The CMS 41 accepts neither <script> tags nor a build step.

What I built

  • Each page is a self-contained HTML fragment 42. The JavaScript runs in the onerror of a deliberately broken image 43, inside an IIFE 44, with feature-prefixed CSS.
  • Defensive start-up: instant skeleton, waiting for the SDK 45 with a timeout 46, an error state and delegated events that survive the Angular host re-rendering, up to the final render 47.
  • I refactored the Store with feature-based names, cached selectors and pure rendering. Its JavaScript went from about 1,150 to about 720 lines.

Materials HTML · CSS · JavaScript · Smartico SDK · CustomEvent · postMessage

Styling inside the shadow DOM

Fig. 5 · Lifters

Customizing Altenar's boosted-odds widget and the chat of a sportsbook 51 without access to their code.

What I built

  • HTML tags in Google Tag Manager inject a stylesheet 56 straight into the shadow root 53 of the widget 52, using adoptedStyleSheets 57.
  • The shadow root and route changes are detected by patching attachShadow and history, so the styles land even when the tree 54 is rebuilt.
  • The selected odd 55 is marked from the SDK event, with anchored selectors so nothing leaks between widgets.

Materials JavaScript · Shadow DOM · Constructable Stylesheets · Google Tag Manager

Analytics dashboard — cumulative curve and dark mode

Fig. 6 · Lifters · Jun 2026

An internal operations dashboard: gross gaming revenue (GGR), cohorts and responsible gambling, per brand.

What I built

  • I built the cumulative GGR curve: actual 61, projection 62, previous month 63 and the daily amount needed 64 to hit the target 65, with monthly cards independent from the chart's range.
  • I shipped the full dark mode with no flash on load: variable-based theming, a codemod over inline styles, and a script that runs before hydration.
  • Status uses only the brand color and neutrals, no green or red, as a product decision.

Materials Next.js · TypeScript · Tailwind · Go · ClickHouse · PostgreSQL

Sentinela — dashboards users assemble

Fig. 7 · personal project · Jun 2026 · open source

An operations monitoring dashboard in React 18 and TypeScript. The data is simulated; the focus is the front-end architecture.

What I built

  • A 12-column grid 72 with draggable, resizable 73 panels 71, and the layout saved in the browser.
  • An explainable anomaly monitor 74: it compares the last day with the median of the last three business days and flags normal, warning or critical.
  • Data behind a repository interface: the deterministic mock can be swapped for the real API without touching the UI, and every panel has its own ErrorBoundary.

Materials React 18 · TypeScript · Vite · React Router · Recharts · react-grid-layout
